# Historical acceptance records

Files below this directory preserve earlier project notes. They are not evidence
for the current worktree unless an entry names a reproducible artifact and the
run is repeated against the current code.

The previous L3 bundle included mocked/historical claims. In particular,
`artifacts/evaluation/history/historical-offline-fake-l3-final.json` is an
offline Fake harness run, while the old Phase 1/2 “E2E” artifacts derive graph,
tool and task metrics from expected labels. Do not report those numbers as live
model or full-graph acceptance results.

The current verification record lives at `docs/acceptance/current.md`.
