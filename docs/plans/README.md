# Historical implementation plans

These plans describe earlier development snapshots and retain the paths used at
the time they were written. They are planning/history documents, not current
commands or proof that an acceptance gate passed. Use repository-root commands
and current paths from `README.md`, `AGENTS.md`, and `specs/README.md`.

Current test inventory and required evidence are registered in
`specs/acceptance/test_matrix.yaml`; live evaluation candidates are stored under
`artifacts/evaluation/candidates/` and are not auto-promoted.
